DENTYAR VERSION 1 - ساخت APK
1) یک مخزن جدید و خالی بسازید.
2) همه محتویات این پوشه را آپلود کنید: www ، capacitor.config.json ، debug.keystore ، .github
3) اگر پوشه .github آپلود نشد: Add file > Create new file و نام فایل را
   .github/workflows/build-apk.yml بنویسید و محتوای همین فایل را Paste کنید.
4) Actions > "DENTYAR V1 - Build APK" > Run workflow
5) پس از علامت سبز: Artifacts > DENTYAR-APK را دانلود و app-debug.apk را نصب کنید.
debug.keystore را حذف نکنید (برای به‌روزرسانی بدون پاک‌شدن اطلاعات).
