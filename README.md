# DENTYAR VERSION 1

دنت‌یار؛ دستیار هوشمند دندان‌پزشکی شما

مرجع ظاهر: DENTYAR V59 — معماری بازنویسی‌شده و مستقل.

## Build APK with GitHub Actions
1. محتویات این پروژه را در ریشه مخزن GitHub قرار دهید.
2. Actions را باز کنید.
3. Workflow با نام **Build DENTYAR VERSION 1 APK** را اجرا کنید.
4. پس از سبز شدن اجرا، از بخش Artifacts فایل `DENTYAR-V1-debug-apk` را دانلود کنید.

## Web
فایل‌های اجرایی داخل `www/` هستند و به صورت PWA نیز قابل استفاده‌اند.
